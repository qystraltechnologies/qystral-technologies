# Qystral Technologies — website redesign starter

This package contains a responsive, premium corporate redesign concept for Qystral Technologies.

## Files
- `index.html` — page structure and content
- `styles.css` — responsive styling
- `script.js` — mobile navigation, current year and email-enquiry form

## Preview
Open `index.html` in a browser. The Google Fonts import requires an internet connection; the page otherwise uses system fallbacks.

## Important before publishing
1. Confirm the current website platform/CMS and theme. This is a platform-neutral front-end implementation, not yet installed into the live CMS.
2. Confirm the public contact email and telephone number.
3. Connect the contact form to a secure form handler or CRM if you want submissions without the visitor's email app opening. The current form uses a `mailto:` handoff.
4. Add genuine project case studies, approved client logos, verified certifications and real testimonials only.
5. Review service scope, privacy policy, terms, cookie requirements and business registration details before launch.
6. Test accessibility, mobile layouts, SEO metadata, analytics and page performance on the actual hosting platform.

No live site, DNS, hosting, existing content or customer data has been changed.

## Dedicated service pages
Each service card on the homepage now links to its own detail page:
- `managed-it-support.html`
- `cloud-microsoft-solutions.html`
- `ai-business-automation.html`
- `web-software-development.html`
- `cybersecurity.html`
- `data-reporting.html`

The individual pages include an overview, detailed service areas, intended customer profile and a contact call-to-action. All pages share the same header, footer, fonts and responsive styling.


## Additional standalone pages
- `our-approach.html` — process and working principles
- `about.html` — company introduction and values
- `contact.html` — dedicated enquiry page

The homepage and service pages link to these pages in their navigation and footers.
